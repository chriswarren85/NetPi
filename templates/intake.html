Accepted Formats

      

        

          
With headers (recommended)

          
Name	IP	Type	VLAN
DSP-01	192.168.1.20	qsys	AV_Control
AMP-01	192.168.1.21	amplifier	AV_Control

          
Tabs, commas, or semicolons all work. Copy from Excel/Sheets with tab separation.

        

        

          
Without headers (positional)

          
192.168.1.20
DSP-01	192.168.1.20
DSP-01	192.168.1.20	qsys

          
Parser anchors on the IP address and assigns surrounding columns by position and pattern.

        

      

      
Recognized Column Header Names

      

        
IP ★ required
ip, ip address, address, ipv4, management ip, static ip

        
Name
name, device, equipment, tag, label, asset tag, device id

        
Type
type, device type, role, category, class

        
VLAN
vlan, vlan id, vlan name, network segment, av network

        
MAC
mac, mac address, hw address, ethernet

        
Vendor
vendor, manufacturer, make, brand, mfr

        
Model
model, model number, part number, sku, product

        
Room
room, zone, area, room/zone, area/room, av zone

        
Serial / Notes / Switch Port
serial, sn, s/n · notes, comment · switch port, port
